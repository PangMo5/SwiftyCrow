# 변경 기록

SwiftyCrow의 주요 변경을 기록해요. 웹사이트와 GitHub 릴리스 노트는 이 파일을 기준으로 표시해요. 릴리스 워크플로는 게시할 때 설치·업데이트 안내를 덧붙여요.

<a id="unreleased"></a>
## 출시 예정

<a id="improvements"></a>
### 개선

- **5개 언어 지원:** 앱, 안내 문서, 웹사이트를 영어·한국어·일본어·중국어 간체·대만식 번체로 사용할 수 있어요.

- **캡처 확대·이동:** 핀치, 스크롤, 드래그로 캡처를 자세히 볼 수 있어요. 줌 도구는 우측 하단 상태바에 있고 배율을 누르면 창에 맞춰져요. 저장·복사에는 원본 해상도의 전체 이미지가 포함돼요.
- **빠른 실시간 갱신:** 화면의 활동에 맞춰 캡처 주기를 조절하고, 바뀌지 않은 픽셀은 건너뛰며, 원문이 바뀌면 이전 작업을 취소해요. 수동 `[capture].interval` 설정은 더 이상 사용하지 않아요.
- **원문 배치를 따르는 번역:** 정렬, 인라인 스타일, 제어 요소와 보호된 코드를 유지해요. 세로 원문도 번역 언어에 맞는 방향으로 표시해요.
- **읽기 어려운 화면 인식 개선:** 인쇄된 말풍선 경계, 후리가나, 회전한 글자, 여러 언어가 섞인 글의 인식을 개선했어요. 불확실한 글에는 검토 표시가 나와요.
- **설치된 모델 활용:** 기본 모델이 없으면 설치된 다른 모델을 사용하고 이유를 알려드려요. 실시간 번역의 정보 버튼을 누르면 자세한 내용을 볼 수 있어요.

<a id="fixes"></a>
### 수정

- **선명한 영역 캡처:** 드래그로 선택한 영역을 화면 픽셀에 맞춰, 글자 인식 전에 불필요한 한 줄이나 한 열이 추가되며 이미지가 다시 확대되는 문제를 막았어요.
- **안정적인 영상 자막:** 영상 압축으로 생기는 미세한 픽셀 변화 때문에 번역 자막이 반복해서 사라지는 문제를 수정했어요. 글자가 바뀌면 계속 인식하고 번역을 갱신해요.
- **별도 번역창 위치 기억:** 실시간 번역을 숨겼다가 다시 켜면 창의 위치와 크기를 복원해요. 디스플레이 연결이 해제되면 보이는 화면 안으로 돌아와요.
- **확대한 이미지의 글자 잔상 수정:** 번역 뒤의 배경을 복원할 때 확대한 글자의 회색 가장자리가 반복되는 글자 조각으로 남는 문제를 수정했어요.
- **언어 선택값 표시:** 설정 파일의 짧은 언어 코드도 같은 언어의 시스템 목록 항목과 일치하도록 했어요.
- **현지화된 메뉴 개선:** 긴 표시 방식 이름도 잘리지 않게 배치하고, 설정·업데이트 버튼은 아이콘과 글자 사이까지 클릭되도록 했어요.

- **캡처 결과 창 이동:** 제목 부분을 드래그해 결과 창을 옮길 수 있어요.
- **안정적인 확대·축소:** 원문을 가리는 배경과 번역문을 함께 합성해, 축소할 때 가려진 원문이 다시 비치지 않도록 했어요.
- **확대 후에도 정확한 창 맞춤:** 캡처 영역 전체를 기준으로 배율을 계산하고 기본 스크롤 막대 배치를 즉시 갱신해요. 스크롤 막대를 항상 표시하도록 설정해도 확대 후 이미지 전체가 다시 보여요.

<a id="290-2026-07-30"></a>
## 2.9.0 (2026-07-30)

<a id="fixed"></a>
### 수정

- **실시간 번역과 캡처가 번역 없이 계속 대기하던 문제 수정:** 앱을 오래 사용하지 않은 뒤 실행하면, 닫고 다시 시도할 때까지 대기 표시만 계속 나올 수 있었어요. macOS는 메모리가 필요하면 글자 인식 모델을 해제하고, 다시 불러오는 데 수십 초가 걸려요. 이제 앱 실행·잠자기 해제·영역 선택 중에 모델을 미리 불러와 보통 선택이 끝나기 전에 준비돼요. 기다려야 할 때는 단순 대기 표시 대신 **글자 인식을 준비하고 있어요**라는 안내가 나와요.
- **실시간 번역을 닫으면 실제로 중지:** 이전에는 창을 화면 밖으로 옮기기만 해서 보이지 않는 애니메이션이 CPU를 계속 쓰고, 지난 결과가 다음 캡처에 섞일 수 있었어요. 이제 두 창을 모두 해제해요.
- **대기 표시가 계속 남던 문제 수정:** 갱신 순서가 뒤바뀌면 다른 동작으로 다시 갱신할 때까지 번역문 없이 대기 표시만 남을 수 있었어요.
- **별도 창에서 계속 대기하던 문제 수정:** 실시간 캡처마다 블러 배경 생성이 다시 시작되어, 넓은 영역에서는 캡처 주기보다 처리가 오래 걸리면 끝나지 않고 창이 비어 있었어요.

<a id="changed-1"></a>
### 변경

- **멈춘 단계 안내:** 화면 캡처, 글자 인식, 번역에 각각 제한 시간을 두어 어느 단계가 응답하지 않는지 알려드려요. 실시간 처리 한 번이 실패해도 전체 번역이 영구히 멈추지 않고 계속 진행돼요.

- **설정 화면 개편:** 시스템 설정처럼 왼쪽에 항목 목록, 오른쪽에 그룹화된 설정을 표시하는 일반 창으로 바뀌었어요. 크기를 조절할 수 있고 열려 있는 동안 일반 앱 창으로 활성화돼요.

<a id="260-2026-06-13"></a>
## 2.6.0 (2026-06-13)

<a id="breaking-changes"></a>
### ⚠️ 호환성 변경

- **실시간 번역 단축키 이름 변경:** `[shortcuts] toggleOverlay`이 `liveOverlay`로 바뀌었어요. 영역을 선택해 실시간 번역을 시작하거나 바꾸며, Space로 창도 선택할 수 있어요. 이전 `toggleOverlay` 항목은 무시되므로 `liveOverlay` 또는 설정 → 단축키에 다시 지정해 주세요.
- **상시 표시 설정 제거:** `[overlay] enabled`을 제거했어요. 이제 영역이나 창을 선택해 실시간 번역을 배치하고 **×**로 닫아요. 이전 키가 남아 있어도 무시돼요.

<a id="whats-new-2"></a>
### 새로운 기능

- **macOS 방식의 창 선택:** 영역 선택 중 **Space**를 누르면 창 선택으로 바뀌어요. 마우스 아래 창이 강조되고 클릭하면 선택돼요. 일반 캡처는 다른 창에 가려져 있어도 해당 창을 캡처하고, 실시간 번역은 그 창 위치에 맞춰져요.
- **드래그로 실시간 번역 시작:** 이제 일반 캡처처럼 **실시간 번역…**을 실행하고 영역을 드래그하거나 Space로 창을 선택하면 바로 번역이 시작돼요. 표시를 켜고 창 위치를 맞춘 뒤 다시 실시간 기능을 켤 필요가 없어요.
- **내장 제어 버튼:** 실시간 동작 중에는 색이 있고 멈추면 단색이 되는 **실시간** 핸들과 닫기용 **×** 버튼이 항상 표시돼요.

<a id="changed-4"></a>
### 변경

- **항상 입력 통과:** 클릭과 스크롤이 뒤쪽 앱으로 전달돼요. 실시간 핸들로 영역을 옮기고 가장자리로 크기를 조절할 수 있어요. 이제 실시간 영역을 배치한 동안에만 창이 존재하며 상시 패널이나 대기 안내는 남지 않아요.
- **단축키 기록창 개선:** 키보드 언어와 관계없이 `⌘S` 같은 영문 키 표기를 유지하고, 한 번 클릭해 기록하며, 이미 쓰는 조합은 알려주고 전용 버튼으로 지울 수 있어요. 캡처 창의 저장·복사 키는 별도 저장소 대신 `config.toml`의 `[shortcuts]` 테이블에 저장돼요. 기본값은 `⌘S`/`⌘C`/`⌘O`/`⌘T`예요. 전역 단축키는 **Magnet**으로 등록해요.

## 2.3.0 (2026-06-01)

<a id="whats-new-5"></a>
### 새로운 기능

- **입력 통과 모드:** 번역문을 위에 둔 채 클릭·스크롤·드래그를 뒤쪽 앱으로 전달하는 설정과 전역 단축키를 추가했어요. 가장자리 크기 조절과 우측 상단 배지 이동은 계속 가능하고, 켜면 강조 테두리와 PASS-THROUGH 배지가 보여요.

<a id="fixed-5"></a>

## 2.2.2 (2026-05-29)

<a id="performance"></a>
### 성능

- **캡처 블러 처리 중에도 반응 유지:** 블러 처리 때문에 캡처 창이 멈추지 않도록 했어요. Core Graphics와 Core Image로 배경을 메인 스레드 밖에서 안전하게 만들어, 가우시안 블러와 영역별 합성 중에도 창을 사용할 수 있어요.

- **번역 대기 표시 수정:** 번역 오류가 나도 대기 표시가 계속 돌 수 있던 문제를 고쳤어요.

## 2.0.0 (2026-05-27)

<a id="highlights-1"></a>
### 주요 변경

- **줄마다 원문 위치에서 번역:** 인식한 줄의 높이에 맞춰 같은 위치에 번역문을 표시해요. Apple 번역의 카메라 모드와 비슷한 방식이에요.
- **떠 있는 글라스 번역창:** 투명한 무테두리 패널을 드래그하고 크기를 바꾸거나, 마우스를 올리면 자동으로 숨길 수 있어요. `⌘C`로 현재 번역문을 복사해요.
- **실시간 모드:** 일정 주기로 영역을 다시 캡처하고, 동작 중에는 `LIVE` 배지가 깜박여요.
- **메뉴 막대 앱:** Dock 아이콘이 없어요. 창을 열지 않아도 한 번 캡처·실시간 전환·표시 전환 전역 단축키를 사용할 수 있어요.
- **원문 자동 감지와 동적 언어 목록:** Vision으로 원문 언어를 감지하고, 설치된 Apple 번역·글자 인식 언어로 목록을 구성해요. 언어를 코드에 고정하지 않아요.
- **줄별 번역 캐시:** 같은 화면을 다시 캡처하면 번역 호출을 건너뛰어요.
- **하나의 TOML 설정:** 설정은 `$XDG_CONFIG_HOME/SwiftyCrow/config.toml`에 저장되고 앱 설정과 양방향으로 동기화돼요.

<a id="under-the-hood"></a>
### 내부 변경

- **기기 내 처리:** ScreenCaptureKit, Vision OCR, Apple 번역으로 모든 처리가 기기 안에서 이루어져요.
- **최신 macOS 26+ API:** **macOS 26 이상**을 대상으로 `SCScreenshotManager`, `RecognizeTextRequest`, 직접 사용하는 `TranslationSession` API로 만들었어요.
- **자동 업데이트:** Sparkle로 자동 업데이트를 제공해요.
