# 서드파티 고지

SwiftyCrow 앱의 의존성 버전과 리비전은 `Tuist/Package.resolved`에 기록돼요. 웹사이트 의존성은 페이지 템플릿에서 버전을 고정해요.

라이선스와 저작권의 [전체 고지 원문](../../THIRD_PARTY_NOTICES.md)을 확인해 주세요. 이 페이지는 설명 부분만 번역했어요.
