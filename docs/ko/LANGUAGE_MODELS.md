# 번역 언어 모델 설치와 관리

SwiftyCrow는 Mac에 모델을 설치해 사용하는 Apple의 기기 내 번역 기능으로 글을 번역해요. 이 안내에서 언어 모델 설치, 확인, 관리 방법을 알아볼 수 있어요.

<a id="quick-start"></a>
## 빠르게 시작하기

번역할 수 없다는 오류가 나오면 다음을 확인해 주세요:

1. Mac에서 **시스템 설정**을 열어 주세요.
2. **일반** → **언어 및 지역**으로 이동해 주세요.
3. 아래쪽의 **번역 언어…**로 이동해 주세요.
4. 번역할 언어 옆의 **다운로드**를 눌러 주세요.
5. 다운로드가 끝날 때까지 기다려 주세요.
6. SwiftyCrow를 다시 실행하고 번역해 보세요.

<a id="understanding-translation-models"></a>
## 번역 모델 알아보기

- **번역 모델이란?** Mac이 글을 번역하는 데 쓰는 소프트웨어 파일이에요. 영어→스페인어처럼 사용할 언어 조합에 필요한 모델을 설치해야 해요.
- **어디에 저장되나요?** Mac의 디스크에 저장되고 macOS가 관리해요. 번역은 클라우드 없이 오프라인으로 이루어져요.
- **공간은 얼마나 필요한가요?** 용량은 언어와 모델마다 달라요. 사용하는 언어를 설치하고, 공간이 필요할 때는 쓰지 않는 다운로드를 지워 주세요.
- **원문·번역 언어를 둘 다 설치해야 하나요?** 네. 영어를 스페인어로 번역한다면 영어와 스페인어 모델이 모두 필요해요.

<a id="step-by-step-installation"></a>
## 설치 순서

<a id="via-system-settings-recommended"></a>
### 시스템 설정에서 설치하기 (권장)

1. 왼쪽 위 Apple 메뉴 → **시스템 설정**을 선택해 주세요.
2. 사이드바에서 **일반**, **언어 및 지역**을 차례로 선택해 주세요.
3. 아래로 스크롤해 **번역 언어…**를 찾아 주세요.
4. 언어 목록에 다음 상태가 표시돼요:
   - **다운로드(파란색):** 모델이 설치되어 있지 않아요. 눌러서 다운로드할 수 있어요.
   - **제거(파란색):** 모델이 설치되어 있어요. 공간이 필요하면 눌러서 지울 수 있어요.
   - **다운로드 중(회색):** 다운로드가 진행 중이에요. 완료될 때까지 기다려 주세요.
5. 필요한 각 언어에서 **다운로드**를 눌러 주세요.
6. 모든 다운로드가 끝날 때까지 기다려 주세요. 시스템 설정에 진행 상태가 표시될 수 있어요.
7. 시스템 설정을 닫고 SwiftyCrow를 다시 실행해 주세요.

<a id="verify-installation"></a>
### 설치 확인

언어 모델이 설치됐는지 확인하려면:

1. 시스템 설정 → 일반 → 언어 및 지역 → 번역 언어…로 돌아가 주세요.
2. 다운로드 대신 **제거**가 보이면 모델이 설치된 거예요.
3. 이제 SwiftyCrow에서 해당 언어를 사용할 수 있어요.

<a id="choosing-which-languages-to-install"></a>
## 설치할 언어 고르기

**원문 언어를 알고 있을 때:**
- 원문 언어(예: 영어)를 설치해 주세요.
- 번역 언어(예: 스페인어, 프랑스어, 독일어)를 설치해 주세요.

**원문 자동 감지를 사용할 때:**
- 설정에서 원문을 **자동 감지**로 두면 캡처에 어떤 언어가 나올지 미리 정하지 않아도 돼요.
- 캡처에 나올 수 있는 모든 언어의 모델을 설치해 주세요.
- 해당 언어의 내용을 캡처했을 때 번역할 수 있도록 준비하는 과정이에요.

**자주 쓰는 언어 조합:**
- 영어 → 스페인어, 프랑스어, 독일어, 중국어, 일본어
- macOS 26 이상에서 지원해요. 언어 목록은 macOS 버전에 따라 달라질 수 있어요.

<a id="troubleshooting"></a>
## 문제 해결

<a id="unable-to-translate-error-appears"></a>
### 번역할 수 없다는 오류가 나올 때

**원인:** 감지한 언어의 모델이 설치되어 있지 않아요.

**해결 방법:**
1. 오류 메시지에서 SwiftyCrow가 감지한 언어를 확인해 주세요.
2. 시스템 설정 → 일반 → 언어 및 지역 → 번역 언어…로 이동해 주세요.
3. 해당 언어를 찾아 **다운로드**를 눌러 주세요.
4. 완료되면 SwiftyCrow에서 다시 번역해 주세요.

<a id="translation-works-for-some-languages-but-not-others"></a>
### 일부 언어만 번역될 때

**원인:** 필요한 모델 중 일부만 설치되어 있어요.

**해결 방법:**
- SwiftyCrow 설정(`⌘,`)에서 원문 언어와 번역 언어를 확인해 주세요.
- 시스템 설정에서 두 언어의 모델을 모두 설치해 주세요.
- 원문이 **자동 감지**라면 캡처에 나올 수 있는 언어의 모델을 모두 설치해 주세요.

<a id="translation-framework-unavailable"></a>
### 번역 프레임워크를 사용할 수 없을 때

**원인:** 이 Mac에서 Apple 번역 프레임워크를 지원하지 않아요.

**해결 방법:** SwiftyCrow는 macOS 26 이상이 필요해요. 시스템 버전을 확인해 주세요:
1. Apple 메뉴 → **이 Mac에 관하여**를 선택해 주세요.
2. **macOS 버전**이 26 이상인지 확인해 주세요.
3. 이전 버전이라면 macOS를 업데이트하거나 다른 번역 도구를 사용해야 해요.

<a id="out-of-disk-space-after-installing-models"></a>
### 모델 설치 후 저장 공간이 부족할 때

**원인:** 다운로드한 언어 모델은 기기의 저장 공간을 사용해요. 필요한 용량은 설치한 언어와 모델에 따라 달라요.

**해결 방법:**
1. 시스템 설정 → 일반 → 언어 및 지역 → 번역 언어…로 이동해 주세요.
2. 쓰지 않는 언어 옆의 **제거**를 눌러 주세요.
3. 해당 언어의 기기 내 번역 모델이 삭제돼요.
4. 필요하면 언제든 다시 다운로드할 수 있어요.

<a id="slow-translation-or-low-latency-vs-high-fidelity"></a>
### 번역이 느릴 때와 번역 방식 선택

설정 → 번역에서 **기본 번역 방식**을 선택할 수 있어요:
- **빠르게(기본값):** 빠르고 가벼워 일상적으로 글을 읽을 때 쓰기 좋아요.
- **자연스럽게:** macOS 26.4 이상의 지원 기기에서 Apple Intelligence를 사용해요. 문장을 더 자연스럽게 만들 수 있지만 모든 문장에서 더 나은 표현을 보장하지는 않아요.

> **번역 방식 설정은 macOS 26.4 이상에서만 적용돼요.** macOS 26.0–26.3에서는 Apple 번역의 기본 방식을 사용하므로 선택을 바꿔도 속도나 정확도에 영향이 없어요.

선택한 방식과 언어 조합을 기준으로 모델을 확인해요. 기본 모델이 없고 다른 방식의 모델이 설치되어 있으면 요청 전에 그 모델을 선택해요. 캡처 상태나 실시간 번역의 정보 아이콘에서 이유를 볼 수 있어요. 기본 설정을 바꾸거나 모델을 자동 다운로드하지는 않아요.

두 방식 모두 모델이 없으면 오류에 언어 조합이 표시돼요. Apple Intelligence 모델이 설치되어 있어도 빠른 번역 방식의 모델까지 설치된 것은 아니에요.

번역이 느리게 느껴진다면:
1. macOS 26.4 이상이라면 설정 → 번역에서 **빠르게**를 선택해 보세요.
2. 앱을 너무 많이 열어 Mac에 부하가 걸려 있지 않은지 확인해 주세요.
3. 긴 내용을 캡처하면 방식과 관계없이 번역에 몇 초가 걸릴 수 있어요.

<a id="feedback"></a>
## 의견 보내기

모델 설치에 문제가 있거나 번역이 계속 실패하면:
1. GitHub의 [SwiftyCrow 이슈](https://github.com/PangMo5/SwiftyCrow/issues)를 확인해 주세요.
2. macOS 버전, 언어 조합, 앱에 표시된 정확한 오류 메시지를 알려 주세요.
3. 번역 전에 모델 다운로드가 완료됐는지도 함께 알려 주세요.

<a id="reading-difficult-sources"></a>
## 읽기 어려운 원문

코드와 기술 식별자로 인식한 부분은 번역문으로 다시 쓰지 않고 원본 픽셀을 유지해요. 원문 복사는 여전히 OCR 결과이므로 정확한 식별자나 코드 구문이 중요할 때는 확인해 주세요.

인식한 문장에 의심스러운 단어가 많거나 혼합 문자 보정이 불확실하면 검토 표시가 나와요. 원문과 비교하라는 안내이며 자동 맞춤법 교정은 아니에요. 작거나 흐리거나 압축된 글자, 모호한 용어는 여전히 잘못 번역될 수 있어요.

인쇄된 대사는 이미지 경계로 이웃 말풍선을 구분해요. 세로 글과 회전한 글의 읽기 방향을 유지해요. 질감이 있는 배경에서는 주변 배경을 참고해 글자를 지우므로, 원문에 가려진 그림을 정확히 복구할 수는 없어요.
