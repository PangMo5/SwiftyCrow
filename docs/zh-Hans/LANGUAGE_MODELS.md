<a id="installing-and-managing-translation-language-models"></a>
# 安装和管理翻译语言模型

SwiftyCrow 使用 Apple 的设备端翻译框架，需要在 Mac 上安装翻译模型。本指南介绍如何安装、检查和管理语言模型。

<a id="quick-start"></a>
## 快速开始

如果提示无法翻译，请按以下步骤检查：

1. 在 Mac 上打开**系统设置**。
2. 前往**通用** → **语言与地区**。
3. 向下滚动至**翻译语言…**。
4. 点击需要翻译的语言旁的**下载**。
5. 等待下载完成。
6. 重新启动 SwiftyCrow，再尝试翻译。

<a id="understanding-translation-models"></a>
## 了解翻译模型

- **翻译模型是什么？** 它是 Mac 用于翻译文字的软件文件。每种语言组合（例如英语→西班牙语）都需要安装相应模型。
- **存储在哪里？** 保存在 Mac 的磁盘上，由 macOS 管理。翻译完全离线进行，无需云服务。
- **需要多少空间？** 下载大小因语言和模型而异。安装常用语言，需要空间时可删除不用的下载。
- **源语言和目标语言都需要安装吗？** 是的。将英语翻译成西班牙语时，需要同时安装英语和西班牙语模型。

<a id="step-by-step-installation"></a>
## 安装步骤

<a id="via-system-settings-recommended"></a>
### 通过系统设置安装（推荐）

1. 点击左上角 Apple 菜单 → **系统设置**。
2. 在侧栏中依次点击**通用**和**语言与地区**。
3. 向下滚动，找到**翻译语言…**。
4. 语言列表会显示以下状态：
   - **下载（蓝色）：** 模型尚未安装，点击即可下载。
   - **移除（蓝色）：** 模型已安装，需要空间时可点击删除。
   - **正在下载（灰色）：** 下载正在进行，请等待完成。
5. 为每种需要的语言点击**下载**。
6. 等待所有下载完成，系统设置中可能显示进度。
7. 关闭系统设置，重新启动 SwiftyCrow。

<a id="verify-installation"></a>
### 验证安装

确认语言模型是否已安装：

1. 返回系统设置 → 通用 → 语言与地区 → 翻译语言…。
2. 如果显示**移除**而不是下载，说明模型已安装。
3. 现在可在 SwiftyCrow 中使用该语言。

<a id="choosing-which-languages-to-install"></a>
## 选择要安装的语言

**已知源语言时：**
- 安装源语言，例如英语。
- 安装目标语言，例如西班牙语、法语、德语。

**自动检测源语言时：**
- 在设置中将源语言设为**自动检测**后，无需事先确定截图中会出现哪种语言。
- 安装截图中可能出现的所有语言模型。
- 这样可为截图中出现的相应语言做好翻译准备。

**常见语言组合：**
- 英语 → 西班牙语、法语、德语、中文、日语
- 支持 macOS 26 及以上版本，语言列表会因 macOS 版本而异。

<a id="troubleshooting"></a>
## 故障排查

<a id="unable-to-translate-error-appears"></a>
### 出现无法翻译错误

**原因：** 检测到的语言尚未安装对应模型。

**解决方法：**
1. 在错误信息中确认 SwiftyCrow 检测到的语言。
2. 前往系统设置 → 通用 → 语言与地区 → 翻译语言…。
3. 找到该语言并点击**下载**。
4. 完成后回到 SwiftyCrow 再次翻译。

<a id="translation-works-for-some-languages-but-not-others"></a>
### 只有部分语言可以翻译

**原因：** 只安装了部分所需模型。

**解决方法：**
- 在 SwiftyCrow 设置（`⌘,`）中确认源语言和目标语言。
- 在系统设置中安装两种语言的模型。
- 使用**自动检测**时，请安装截图中可能出现的所有语言模型。

<a id="translation-framework-unavailable"></a>
### 无法使用翻译框架

**原因：** 这台 Mac 不支持 Apple 翻译框架。

**解决方法：** SwiftyCrow 需要 macOS 26 或更高版本，请检查系统版本：
1. 点击 Apple 菜单 → **关于本机**。
2. 确认 **macOS 版本**为 26 或更高。
3. 版本较旧时，需要升级 macOS 或使用其他翻译工具。

<a id="out-of-disk-space-after-installing-models"></a>
### 安装模型后存储空间不足

**原因：** 下载的语言模型占用本地存储空间，总量取决于已安装的语言和模型。

**解决方法：**
1. 前往系统设置 → 通用 → 语言与地区 → 翻译语言…。
2. 点击不常用语言旁的**移除**。
3. 这会删除该语言的本地翻译模型。
4. 需要时可随时重新下载。

<a id="slow-translation-or-low-latency-vs-high-fidelity"></a>
### 翻译较慢或如何选择翻译方式

在设置 → 翻译中可选择**首选翻译方式**：
- **快速（默认）：** 更快、更轻量，适合日常阅读。
- **高质量：** 在运行 macOS 26.4 及以上版本的支持设备上使用 Apple Intelligence。可能让表达更流畅，但不保证每段文字都会更好。

> **翻译方式设置仅在 macOS 26.4 及以上版本生效。** macOS 26.0–26.3 使用 Apple 翻译框架的默认方式，切换选项不会改变速度或准确性。

按所选方式和语言组合检查模型。首选模型缺失而其他方式的模型已安装时，会在发出请求前选择已安装的模型。截图状态或实时翻译的信息图标会说明原因，不会修改偏好设置或自动下载模型。

两种方式均无已安装模型时，错误会显示语言组合。安装了 Apple Intelligence 模型，并不代表快速方式的对应模型也已安装。

如果觉得翻译较慢：
1. 在 macOS 26.4 及以上版本中，可到设置 → 翻译尝试**快速**方式。
2. 检查是否打开过多应用，导致 Mac 负载过高。
3. 截图内容较长时，无论哪种方式都可能需要数秒完成翻译。

<a id="feedback"></a>
## 反馈

如果模型安装遇到问题，或翻译仍然失败：
1. 查看 GitHub 上的 [SwiftyCrow Issues](https://github.com/PangMo5/SwiftyCrow/issues)。
2. 请提供 macOS 版本、语言组合和应用中显示的完整错误信息。
3. 同时说明翻译前模型是否已完整下载。

<a id="reading-difficult-sources"></a>
## 识别困难的原文

识别为代码或技术标识符的内容会保留原始像素，不会重新绘制成译文。复制原文仍来自 OCR；需要精确标识符或代码语法时，请核对结果。

识别文本中有较多可疑词语，或混合文字修复不确定时，会显示核对提示。它提醒你与原文对照，并不自动纠正拼写。过小、模糊、压缩的文字和含义不明的术语仍可能翻译错误。

印刷对话会利用图像边界区分相邻气泡，保留竖排和旋转文字的阅读方向。在纹理背景上，使用邻近背景样本去除字形，因此无法精确恢复原文字母遮住的图案。
