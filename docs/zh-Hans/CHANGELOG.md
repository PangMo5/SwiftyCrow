# 更新日志

记录 SwiftyCrow 的主要变化。网站和 GitHub 发布说明均以此文件为准，发布流程会附加安装与更新说明。

<a id="2100-2026-09-17"></a>
## 2.10.0 (2026-09-17)

<a id="improvements"></a>
### 改进

- **保留原文布局的翻译：** 尽量保留原文的段落对齐和文字样式。识别为代码或命令的文字不翻译，保留原样。竖排文字也会按译文语言适合的方向排列。
- **改善复杂内容识别：** 改进印刷对话边界、注音、旋转文字和混合语言识别。对不确定的文字显示核对提示。
- **截图缩放与移动：** 移动截图窗口，通过捏合、滚动或拖动仔细查看图片。点击缩放比例可适配整张截图，并可按原始分辨率保存或复制完整译图。
- **实时翻译：** 根据画面变化调整更新间隔，跳过未变化的内容并取消过时任务。隐藏后可在记住的区域与翻译窗口位置恢复；断开显示器后窗口会回到可见屏幕。
- **使用可用的本地模型：** 缺少首选模型时，会使用其他已安装模型并说明原因。点击实时翻译的信息按钮可查看详情。
- **更清晰的翻译菜单：** 直接启动截图或实时翻译，并查看所选语言。仅在悬浮翻译开启时显示实时控制工具。
- **快速设置与新功能介绍：** 新用户可在首次截图前准备屏幕访问权限、语言下载和快捷键。现有用户可查看功能版本的主要变化，两种指南均可从菜单栏打开。
- **默认快捷键：** 使用 ⇧⌘1 截图，使用 ⇧⌘2 选择实时翻译区域。可在快速设置或设置中自定义，现有自定义绑定会保留。
- **五种界面语言：** 应用、指南和网站支持英语、韩语、日语、简体中文和面向台湾的繁体中文。

<a id="fixes"></a>
### 修复

- **清晰的区域截图：** 拖选区域与屏幕像素对齐，避免在文字识别前因多出一行或一列像素而重新缩放图像。
- **正确显示所选语言：** 配置文件中的等效短语言代码现在能匹配系统语言选择器。

<a id="configuration"></a>
### 配置

- 不再使用手动 `[capture].interval` 设置，实时翻译会自动调整更新间隔。

<a id="290-2026-07-30"></a>
## 2.9.0 (2026-07-30)

<a id="fixed"></a>
### 修复

- **修复实时翻译和截图一直等待却不翻译的问题：** 应用闲置一段时间后使用，可能只显示等待动画，直到关闭后重试。macOS 会在需要内存时卸载文字识别模型，重新加载需数十秒。现在会在启动、唤醒和拖动选择区域时预加载模型，通常在选择完成前就已准备好。仍需等待时，会显示**正在准备文字识别**，而不是只有等待动画。
- **关闭实时翻译后真正停止：** 以前隐藏时只是将窗口移到屏幕外，动画仍持续消耗 CPU，旧结果也可能混入下一次截图。现在会释放两个窗口。
- **修复等待动画不消失的问题：** 更新顺序错乱时，可能一直只显示等待动画而没有译文，直到其他操作触发刷新。
- **修复独立窗口一直等待的问题：** 每次实时截图都会重新生成模糊背景。当区域较大、处理时间超过截图间隔时，任务始终无法完成，窗口一直为空。

<a id="changed-1"></a>
### 变更

- **提示停滞的处理阶段：** 为屏幕截图、文字识别和翻译分别设置超时，明确说明哪个阶段未响应。某一次实时处理失败后，后续处理仍会继续，不会永久停止。

## 2.8.0 (2026-07-15)

<a id="whats-new"></a>
### 新功能

- **按需使用预设区域：** 先确定区域，需要时再翻译。应用会记住上次位置，可用新的**显示或隐藏实时翻译**快捷键，或菜单中的**在上次区域显示**／**隐藏实时翻译**切换，无需再次拖选。适合偶尔查看的游戏面板或固定信息。关闭后会彻底结束窗口和处理，直到再次开启前都不会截图、识别或翻译。在 `[shortcuts] toggleLiveOverlay` 或设置 → 快捷键中绑定。 (#9)

<a id="changed-2"></a>
### 变更

- **重新设计设置：** 设置改为可调整大小的标准窗口，左侧为类似系统设置的侧栏，右侧为分组表单。打开期间会作为普通应用窗口激活。
- **更简洁的实时翻译界面：** **实时**和**×**按钮现在与移动手柄一样，仅在鼠标位于区域上方时显示。进度动画涵盖截图、文字识别和翻译，首次截图较慢时也能立即看到处理状态。

## 2.7.0 (2026-06-18)

<a id="whats-new-1"></a>
### 新功能

- **原位竖排翻译：** 按阅读顺序识别包括日文和繁体中文在内的竖排 CJK 段落。译文字形自上而下、列自右向左排列，并保留原文的字号比例。
- **理解文档结构：** 按阅读顺序组织段落，将注音与正文分离，并检测每个文本块的方向。漫画和多栏页面等复杂内容的识别更清晰。

<a id="fixed-1"></a>
### 修复

- **缺少语言模型时提供指引：** 未安装模型时会提示下一步操作。截图语言的模型缺失时，结果窗口、实时翻译、独立窗口和菜单栏都会显示提示。**打开设置**可前往下载位置，**不再显示**可隐藏提醒。

<a id="changed-3"></a>
### 变更

- **统一使用文档识别：** 移除文本／文档切换，始终分析文档布局。`config.toml` 中的 `[recognition]` 表将被忽略。

<a id="260-2026-06-13"></a>
## 2.6.0 (2026-06-13)

<a id="breaking-changes"></a>
### ⚠️ 不兼容变更

- **更名实时翻译快捷键：** `[shortcuts] toggleOverlay` 已改名为 `liveOverlay`。现在通过选择区域来启动或替换实时翻译，也可用 Space 选择窗口。旧 `toggleOverlay` 项会被忽略，请在 `liveOverlay` 或设置 → 快捷键中重新绑定。
- **移除常驻显示设置：** 已移除 `[overlay] enabled`。现在通过选择区域或窗口放置实时翻译，再用**×**关闭。旧键即使保留也会被忽略。

<a id="whats-new-2"></a>
### 新功能

- **macOS 风格的窗口选择：** 选择区域时按 **Space** 可切换为窗口选择。鼠标下方窗口会高亮，点击即可选中。普通截图即使窗口被遮挡也能截取，实时翻译则会贴合该窗口。
- **拖选即可开始实时翻译：** 现在与普通截图一样，启动**实时翻译…**后拖选区域，或用 Space 选择窗口，即会开始翻译。无需先启用覆盖层、调整位置，再开启实时模式。
- **内置控制按钮：** 始终显示**实时**手柄和关闭用的**×**按钮；实时运行时手柄带颜色，暂停时为单色。

<a id="changed-4"></a>
### 变更

- **始终透传输入：** 点击和滚动会传递给下方应用。可用实时手柄移动区域，用边缘调整大小。仅在放置实时区域期间保留窗口，不再留下常驻面板或空闲提示。
- **改进快捷键录入：** 无论键盘布局如何，都使用 `⌘S` 等稳定的英文按键符号；单击即可录入，冲突时会提示，并提供专用清除按钮。截图窗口的保存、复制键现存于 `config.toml` 的 `[shortcuts]` 表，默认值为 `⌘S`/`⌘C`/`⌘O`/`⌘T`，不再单独存储。全局快捷键使用 **Magnet** 注册。

<a id="222-2026-05-29"></a>
## 2.2.2 (2026-05-29)

<a id="performance"></a>
### 性能

- **模糊处理不再阻塞截图：** 使用线程安全的 Core Graphics／Core Image 在主线程之外生成背景，运行高斯模糊和逐区域合成时，结果窗口仍能响应。
- **更快的翻译：** 在单个设备端翻译会话中批量处理全部文本，不再为每行创建会话。结果仍会准备好一条就显示一条。
- **修复翻译等待动画：** 修复翻译出错后等待动画可能持续显示的问题。

## 2.0.0 (2026-05-27)

<a id="highlights-1"></a>
### 重点更新

- **逐行原位翻译：** 在原文位置按原始行高显示每行译文，类似 Apple 翻译的相机模式。
- **浮动玻璃翻译层：** 透明无边框面板可拖动、调整大小，并可在鼠标悬停时自动隐藏。按 `⌘C` 复制当前译文。
- **实时模式：** 按固定间隔重新截图，运行时 `LIVE` 标记会闪动。
- **菜单栏应用：** 没有 Dock 图标，即使没有打开窗口，也能使用单次截图、实时切换和显示切换的全局快捷键。
- **自动检测原文和动态语言列表：** 使用 Vision 检测原文语言，从已安装的 Apple 翻译和文字识别语言生成列表，不在代码中写死语言。
- **逐行翻译缓存：** 再次截取相同画面时跳过翻译调用。
- **单一 TOML 配置：** 设置存储在 `$XDG_CONFIG_HOME/SwiftyCrow/config.toml`，与应用内设置双向同步。

<a id="under-the-hood"></a>
### 内部改进

- **设备端处理：** 通过 ScreenCaptureKit、Vision OCR 和 Apple 翻译在设备上完成全部处理。
- **现代 macOS 26+ API：** 面向 **macOS 26 及以上版本**，使用 `SCScreenshotManager`、`RecognizeTextRequest` 和直接调用的 `TranslationSession` API。
- **自动更新：** 通过 Sparkle 提供自动更新。
