# 更新紀錄

記錄 SwiftyCrow 的主要變更。網站與 GitHub 發布說明均以此檔案為準，發布流程會附加安裝與更新說明。

<a id="2100-2026-09-17"></a>
## 2.10.0 (2026-09-17)

<a id="improvements"></a>
### 改善

- **保留原文配置的翻譯：** 盡量保留原文的段落對齊與文字樣式。辨識為程式碼或指令的文字不翻譯，保留原樣。直排文字也會依譯文語言適合的方向排列。
- **改善複雜內容辨識：** 改進印刷對話邊界、注音、旋轉文字與混合語言辨識。對不確定的文字顯示核對提示。
- **擷取縮放與移動：** 移動擷取視窗，透過捏合、捲動或拖曳仔細查看圖片。點選縮放比例可符合整張擷取畫面，並可依原始解析度儲存或複製完整譯圖。
- **即時翻譯：** 依畫面變化調整更新間隔，跳過未變化的內容並取消過時工作。隱藏後可在記住的區域與翻譯視窗位置恢復；中斷顯示器連線後視窗會回到可見螢幕。
- **使用可用的本機模型：** 缺少偏好模型時，會使用其他已安裝模型並說明原因。點按即時翻譯的資訊按鈕即可查看詳情。
- **更清楚的翻譯選單：** 直接啟動擷取或即時翻譯，並查看所選語言。僅在浮動翻譯開啟時顯示即時控制工具。
- **快速設定與新功能介紹：** 新使用者可在首次擷取前準備螢幕存取權限、語言下載與快捷鍵。現有使用者可查看功能版本的主要變更，兩種指南皆可從選單列開啟。
- **預設快捷鍵：** 使用 ⇧⌘1 擷取，使用 ⇧⌘2 選取即時翻譯區域。可在快速設定或設定中自訂，現有自訂綁定會保留。
- **五種介面語言：** App、指南與網站支援英語、韓語、日語、簡體中文及臺灣用語的繁體中文。

<a id="fixes"></a>
### 修正

- **清晰的區域截圖：** 拖曳選取的範圍對齊螢幕像素，避免在文字辨識前因多出一列或一欄像素而重新縮放影像。
- **正確顯示所選語言：** 設定檔中的等效短語言代碼現在能對應系統語言選擇器。

<a id="configuration"></a>
### 設定

- 不再使用手動 `[capture].interval` 設定，即時翻譯會自動調整更新間隔。

<a id="290-2026-07-30"></a>
## 2.9.0 (2026-07-30)

<a id="fixed"></a>
### 修正

- **修正即時翻譯與擷取一直等待卻未翻譯的問題：** App 閒置一段時間後使用，可能只顯示等待動畫，直到關閉後重試。macOS 會在需要記憶體時卸載文字辨識模型，重新載入需數十秒。現在會在啟動、喚醒及拖移選取區域時預先載入模型，通常在選取完成前就已準備好。仍需等待時，會顯示**正在準備文字辨識**，而非只有等待動畫。
- **關閉即時翻譯後確實停止：** 先前隱藏時只是將視窗移到螢幕外，動畫仍持續消耗 CPU，舊結果也可能混入下一次擷取。現在會釋放兩個視窗。
- **修正等待動畫未消失的問題：** 更新順序錯亂時，可能一直只顯示等待動畫而沒有譯文，直到其他操作觸發更新。
- **修正獨立視窗一直等待的問題：** 每次即時擷取都會重新產生模糊背景。當區域較大、處理時間超過擷取間隔時，工作始終無法完成，視窗一直空白。

<a id="changed-1"></a>
### 變更

- **提示停滯的處理階段：** 為螢幕擷取、文字辨識與翻譯分別設定逾時，清楚說明哪個階段未回應。某一次即時處理失敗後，後續處理仍會繼續，不會永久停止。

<a id="280-2026-07-15"></a>
## 2.8.0 (2026-07-15)

<a id="whats-new"></a>
### 新功能

- **隨需使用預設區域：** 先確定區域，需要時再翻譯。App 會記住上次位置，可用新的**顯示或隱藏即時翻譯**快速鍵，或選單中的**顯示在上次區域**／**隱藏即時翻譯**切換，不必再次拖選。適合偶爾查看的遊戲面板或固定資訊。關閉後會完整結束視窗與處理，直到再次開啟前都不會擷取、辨識或翻譯。在 `[shortcuts] toggleLiveOverlay` 或設定 → 快速鍵中綁定。 (#9)

<a id="changed-2"></a>
### 變更

- **重新設計設定：** 設定改為可調整大小的標準視窗，左側為類似系統設定的側邊欄，右側為分組表單。開啟期間會以一般 App 視窗啟用。
- **更簡潔的即時翻譯介面：** **即時**與**×**按鈕現在和移動把手一樣，僅在游標位於區域上方時顯示。進度動畫涵蓋擷取、文字辨識與翻譯，首次擷取較慢時也能立即看到處理狀態。

## 2.7.0 (2026-06-18)

<a id="whats-new-1"></a>
### 新功能

<a id="changed-3"></a>
### 變更

- **統一使用文件辨識：** 移除文字／文件切換，一律分析文件配置。`config.toml` 中的 `[recognition]` 資料表會被忽略。

<a id="260-2026-06-13"></a>
## 2.6.0 (2026-06-13)

<a id="breaking-changes"></a>
### ⚠️ 不相容變更

- **重新命名即時翻譯快速鍵：** `[shortcuts] toggleOverlay` 已改名為 `liveOverlay`。現在透過選取區域啟動或替換即時翻譯，也能用 Space 選取視窗。舊 `toggleOverlay` 項目會被忽略，請在 `liveOverlay` 或設定 → 快速鍵中重新綁定。
- **移除常駐顯示設定：** 已移除 `[overlay] enabled`。現在透過選取區域或視窗放置即時翻譯，再用**×**關閉。即使保留舊鍵也會被忽略。

<a id="whats-new-2"></a>
### 新功能

- **macOS 風格的視窗選取：** 選取區域時按 **Space** 可切換為視窗選取。游標下方視窗會反白，點按即可選取。一般擷取即使視窗被遮擋也能擷取，即時翻譯則會貼合該視窗。
- **拖選即可開始即時翻譯：** 現在與一般擷取相同，啟動**即時翻譯…**後拖選區域，或用 Space 選取視窗，即會開始翻譯。不必先啟用覆蓋層、調整位置，再開啟即時模式。
- **內建控制按鈕：** 一律顯示**即時**把手與關閉用的**×**按鈕；即時執行時把手帶有顏色，暫停時為單色。

<a id="changed-4"></a>
### 變更

- **一律傳遞輸入：** 點按與捲動會傳遞給下方 App。可用即時把手移動區域，用邊緣調整大小。僅在放置即時區域期間保留視窗，不再留下常駐面板或閒置提示。
- **改進快速鍵輸入：** 無論鍵盤配置為何，都使用 `⌘S` 等固定的英文按鍵符號；點按一次即可輸入，衝突時會提示，並提供專用清除按鈕。擷取視窗的儲存、複製鍵現存於 `config.toml` 的 `[shortcuts]` 資料表，預設值為 `⌘S`/`⌘C`/`⌘O`/`⌘T`，不再個別儲存。全域快速鍵使用 **Magnet** 註冊。

<a id="222-2026-05-29"></a>
## 2.2.2 (2026-05-29)

<a id="performance"></a>
### 效能

- **模糊處理不再阻塞擷取：** 使用執行緒安全的 Core Graphics／Core Image，在主執行緒之外產生背景；執行高斯模糊與逐區域合成時，結果視窗仍能回應。
- **更快的翻譯：** 在單一裝置端翻譯工作階段中批次處理全部文字，不再為每行建立工作階段。結果仍會完成一條就顯示一條。
- **修正翻譯等待動畫：** 修正翻譯出錯後等待動畫可能持續顯示的問題。

## 2.2.1 (2026-05-28)

<a id="fixed-6"></a>
### 修正

- **以原始解析度儲存與複製：** 先前輸出受螢幕視窗大小限制，較高的擷取內容縮小顯示後，也會以較低解析度儲存。現在儲存或複製時，會暫時將視窗調整到與來源像素 1:1 的大小，再恢復原狀。

<a id="200-2026-05-27"></a>
## 2.0.0 (2026-05-27)

<a id="highlights-1"></a>
### 重點更新

- **逐行原位翻譯：** 在原文位置依原始行高顯示每行譯文，類似 Apple 翻譯的相機模式。
- **浮動玻璃翻譯層：** 透明無邊框面板可拖移、調整大小，並可在游標停留時自動隱藏。按 `⌘C` 複製目前譯文。
- **即時模式：** 依固定間隔重新擷取，執行時 `LIVE` 標記會閃動。
- **選單列 App：** 沒有 Dock 圖示，即使未開啟視窗，也能使用單次擷取、即時切換與顯示切換的全域快速鍵。
- **自動偵測原文與動態語言清單：** 使用 Vision 偵測原文語言，從已安裝的 Apple 翻譯與文字辨識語言產生清單，不在程式碼中固定語言。
- **逐行翻譯快取：** 再次擷取相同畫面時略過翻譯呼叫。
- **單一 TOML 設定：** 設定儲存在 `$XDG_CONFIG_HOME/SwiftyCrow/config.toml`，與 App 內設定雙向同步。

<a id="under-the-hood"></a>
### 內部改善

- **裝置端處理：** 透過 ScreenCaptureKit、Vision OCR 與 Apple 翻譯，在裝置上完成全部處理。
- **現代 macOS 26+ API：** 以 **macOS 26 以上版本**為目標，使用 `SCScreenshotManager`、`RecognizeTextRequest` 與直接呼叫的 `TranslationSession` API。
- **自動更新：** 透過 Sparkle 提供自動更新。

## 1.2.0 (2023-02-06)
