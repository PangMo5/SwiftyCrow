<a id="installing-and-managing-translation-language-models"></a>
# 安裝與管理翻譯語言模型

SwiftyCrow 使用 Apple 的裝置端翻譯框架，需要在 Mac 上安裝翻譯模型。這份指南說明如何安裝、檢查與管理語言模型。

<a id="quick-start"></a>
## 快速開始

如果提示無法翻譯，請依下列步驟檢查：

1. 在 Mac 上開啟**系統設定**。
2. 前往**一般** → **語言與地區**。
3. 向下捲動至**翻譯語言…**。
4. 點按需要翻譯的語言旁的**下載**。
5. 等待下載完成。
6. 重新啟動 SwiftyCrow，再嘗試翻譯。

<a id="understanding-translation-models"></a>
## 認識翻譯模型

- **翻譯模型是什麼？** 它是 Mac 用來翻譯文字的軟體檔案。每種語言組合（例如英語→西班牙語）都需要安裝對應模型。
- **儲存在哪裡？** 儲存在 Mac 的磁碟上，由 macOS 管理。翻譯完全離線進行，不需要雲端服務。
- **需要多少空間？** 下載大小因語言與模型而異。安裝常用語言，需要空間時可刪除不用的下載。
- **原文與翻譯語言都需要安裝嗎？** 是的。將英語翻譯成西班牙語時，需要同時安裝英語與西班牙語模型。

<a id="step-by-step-installation"></a>
## 安裝步驟

<a id="via-system-settings-recommended"></a>
### 透過系統設定安裝（建議）

1. 點按左上角 Apple 選單 → **系統設定**。
2. 在側邊欄中依序點按**一般**與**語言與地區**。
3. 向下捲動，找到**翻譯語言…**。
4. 語言清單會顯示下列狀態：
   - **下載（藍色）：** 模型尚未安裝，點按即可下載。
   - **移除（藍色）：** 模型已安裝，需要空間時可點按刪除。
   - **正在下載（灰色）：** 下載正在進行，請等待完成。
5. 為每種需要的語言點按**下載**。
6. 等待所有下載完成，系統設定中可能會顯示進度。
7. 關閉系統設定，重新啟動 SwiftyCrow。

<a id="verify-installation"></a>
### 確認安裝

確認語言模型是否已安裝：

1. 返回系統設定 → 一般 → 語言與地區 → 翻譯語言…。
2. 如果顯示**移除**而不是下載，代表模型已安裝。
3. 現在可在 SwiftyCrow 中使用該語言。

<a id="choosing-which-languages-to-install"></a>
## 選擇要安裝的語言

**已知原文語言時：**
- 安裝原文語言，例如英語。
- 安裝翻譯語言，例如西班牙語、法語、德語。

**自動偵測原文語言時：**
- 在設定中將原文語言設為**自動偵測**後，不必事先確定擷取內容中會出現哪種語言。
- 安裝擷取內容中可能出現的所有語言模型。
- 這樣即可為擷取內容中出現的對應語言做好翻譯準備。

**常見語言組合：**
- 英語 → 西班牙語、法語、德語、中文、日語
- 支援 macOS 26 以上版本，語言清單會依 macOS 版本而異。

<a id="troubleshooting"></a>
## 疑難排解

<a id="unable-to-translate-error-appears"></a>
### 出現無法翻譯錯誤

**原因：** 偵測到的語言尚未安裝對應模型。

**解決方式：**
1. 在錯誤訊息中確認 SwiftyCrow 偵測到的語言。
2. 前往系統設定 → 一般 → 語言與地區 → 翻譯語言…。
3. 找到該語言並點按**下載**。
4. 完成後回到 SwiftyCrow 再次翻譯。

<a id="translation-works-for-some-languages-but-not-others"></a>
### 只有部分語言可以翻譯

**原因：** 只安裝了部分所需模型。

**解決方式：**
- 在 SwiftyCrow 設定（`⌘,`）中確認原文語言與翻譯語言。
- 在系統設定中安裝兩種語言的模型。
- 使用**自動偵測**時，請安裝擷取內容中可能出現的所有語言模型。

<a id="translation-framework-unavailable"></a>
### 無法使用翻譯框架

**原因：** 這部 Mac 不支援 Apple 翻譯框架。

**解決方式：** SwiftyCrow 需要 macOS 26 或以上版本，請檢查系統版本：
1. 點按 Apple 選單 → **關於這台 Mac**。
2. 確認 **macOS 版本**為 26 或以上。
3. 版本較舊時，需要升級 macOS 或使用其他翻譯工具。

<a id="out-of-disk-space-after-installing-models"></a>
### 安裝模型後儲存空間不足

**原因：** 下載的語言模型會占用本機儲存空間，總量取決於已安裝的語言與模型。

**解決方式：**
1. 前往系統設定 → 一般 → 語言與地區 → 翻譯語言…。
2. 點按不常用語言旁的**移除**。
3. 這會刪除該語言的本機翻譯模型。
4. 需要時可隨時重新下載。

<a id="slow-translation-or-low-latency-vs-high-fidelity"></a>
### 翻譯較慢或如何選擇翻譯方式

在設定 → 翻譯中可選擇**偏好的翻譯方式**：
- **快速（預設）：** 更快、更輕量，適合日常閱讀。
- **高品質：** 在執行 macOS 26.4 以上版本的支援裝置上使用 Apple Intelligence。可能讓表達更流暢，但不保證每段文字都會更好。

> **翻譯方式設定僅在 macOS 26.4 以上版本生效。** macOS 26.0–26.3 使用 Apple 翻譯框架的預設方式，切換選項不會改變速度或準確性。

會依所選方式與語言組合檢查模型。偏好模型缺少而其他方式的模型已安裝時，會在送出要求前選擇已安裝的模型。擷取狀態或即時翻譯的資訊圖示會說明原因，不會修改偏好設定或自動下載模型。

兩種方式都沒有已安裝模型時，錯誤會顯示語言組合。安裝了 Apple Intelligence 模型，不代表快速方式的對應模型也已安裝。

如果覺得翻譯較慢：
1. 在 macOS 26.4 以上版本中，可到設定 → 翻譯嘗試**快速**方式。
2. 檢查是否開啟過多 App，導致 Mac 負載過高。
3. 擷取內容較長時，無論哪種方式都可能需要數秒完成翻譯。

<a id="feedback"></a>
## 意見回饋

如果模型安裝遇到問題，或翻譯仍然失敗：
1. 查看 GitHub 上的 [SwiftyCrow Issues](https://github.com/PangMo5/SwiftyCrow/issues)。
2. 請提供 macOS 版本、語言組合與 App 中顯示的完整錯誤訊息。
3. 也請說明翻譯前模型是否已完整下載。

<a id="reading-difficult-sources"></a>
## 辨識困難的原文

辨識為程式碼或技術識別字的內容會保留原始像素，不會重新繪製成譯文。複製原文仍來自 OCR；需要精確識別字或程式碼語法時，請核對結果。

辨識文字中有較多可疑詞語，或混合文字修復不確定時，會顯示核對提示。這是提醒你與原文對照，不會自動更正拼字。過小、模糊、壓縮的文字及含義不明的術語仍可能翻譯錯誤。

印刷對話會利用影像邊界區分相鄰對話框，保留直排與旋轉文字的閱讀方向。在紋理背景上，會使用鄰近背景樣本移除字形，因此無法精確還原原文字形遮住的圖案。
