<a id="installing-and-managing-translation-language-models"></a>
# 翻訳言語モデルのインストールと管理

SwiftyCrowは、Macにモデルをインストールして使うAppleのオンデバイス翻訳で文章を翻訳します。このガイドでは、言語モデルのインストール、確認、管理方法を説明します。

<a id="quick-start"></a>
## クイックスタート

翻訳できないというエラーが出たら、次を確認してください：

1. Macで**システム設定**を開いてください。
2. **一般** → **言語と地域**に進んでください。
3. 下の方にある**翻訳言語…**を選んでください。
4. 翻訳に使う言語の横の**ダウンロード**を押してください。
5. ダウンロードが終わるまでお待ちください。
6. SwiftyCrowを再起動して翻訳を試してください。

<a id="understanding-translation-models"></a>
## 翻訳モデルについて

- **翻訳モデルとは？** Macが文章を翻訳するために使うソフトウェアファイルです。英語→スペイン語のように、使う言語の組み合わせに必要なモデルをインストールします。
- **どこに保存されますか？** Macのディスクに保存され、macOSが管理します。翻訳はクラウドを使わずオフラインで行います。
- **容量はどのくらい必要ですか？** 言語やモデルによって異なります。使う言語をインストールし、空き容量が必要なときは使わないダウンロードを削除してください。
- **原文と翻訳先の両方が必要ですか？** はい。英語をスペイン語に翻訳する場合は、英語とスペイン語の両方のモデルが必要です。

<a id="step-by-step-installation"></a>
## インストールの手順

<a id="via-system-settings-recommended"></a>
### システム設定からインストール（推奨）

1. 左上のAppleメニュー → **システム設定**を選んでください。
2. サイドバーで**一般**、**言語と地域**の順に選んでください。
3. 下にスクロールして**翻訳言語…**を探してください。
4. 言語一覧には次の状態が表示されます：
   - **ダウンロード（青色）：** モデルがインストールされていません。押すとダウンロードできます。
   - **削除（青色）：** モデルはインストール済みです。空き容量が必要な場合は押して削除できます。
   - **ダウンロード中（灰色）：** ダウンロードが進行中です。完了するまでお待ちください。
5. 必要な各言語で**ダウンロード**を押してください。
6. すべてのダウンロードが終わるまでお待ちください。システム設定に進行状況が表示されることがあります。
7. システム設定を閉じてSwiftyCrowを再起動してください。

<a id="verify-installation"></a>
### インストールを確認

言語モデルのインストールを確認するには：

1. システム設定 → 一般 → 言語と地域 → 翻訳言語…に戻ってください。
2. ダウンロードではなく**削除**が表示されていれば、インストール済みです。
3. これでSwiftyCrowでその言語を使えます。

<a id="choosing-which-languages-to-install"></a>
## インストールする言語を選ぶ

**原文の言語が分かっている場合：**
- 原文の言語（例：英語）をインストールしてください。
- 翻訳先の言語（例：スペイン語、フランス語、ドイツ語）をインストールしてください。

**原文の自動検出を使う場合：**
- 設定で原文を**自動検出**にすると、キャプチャに含まれる言語を事前に指定する必要がありません。
- キャプチャに含まれそうなすべての言語のモデルをインストールしてください。
- その言語の内容をキャプチャしたときに翻訳できるよう準備するためです。

**よく使う言語の組み合わせ：**
- 英語 → スペイン語、フランス語、ドイツ語、中国語、日本語
- macOS 26以降に対応します。言語一覧はmacOSのバージョンによって変わる場合があります。

<a id="troubleshooting"></a>
## トラブルシューティング

<a id="unable-to-translate-error-appears"></a>
### 翻訳できないというエラーが出るとき

**原因：** 検出した言語のモデルがインストールされていません。

**対処方法：**
1. エラーメッセージでSwiftyCrowが検出した言語を確認してください。
2. システム設定 → 一般 → 言語と地域 → 翻訳言語…に進んでください。
3. その言語を探して**ダウンロード**を押してください。
4. 完了したらSwiftyCrowでもう一度翻訳してください。

<a id="translation-works-for-some-languages-but-not-others"></a>
### 一部の言語だけ翻訳できるとき

**原因：** 必要なモデルの一部だけがインストールされています。

**対処方法：**
- SwiftyCrowの設定（`⌘,`）で原文と翻訳先の言語を確認してください。
- システム設定で両方の言語のモデルをインストールしてください。
- 原文が**自動検出**の場合は、キャプチャに含まれそうなすべての言語のモデルをインストールしてください。

<a id="translation-framework-unavailable"></a>
### 翻訳フレームワークを利用できないとき

**原因：** このMacではAppleの翻訳フレームワークに対応していません。

**対処方法：** SwiftyCrowにはmacOS 26以降が必要です。システムのバージョンを確認してください：
1. Appleメニュー → **このMacについて**を選んでください。
2. **macOSのバージョン**が26以降か確認してください。
3. 以前のバージョンの場合は、macOSを更新するか別の翻訳ツールを使ってください。

<a id="out-of-disk-space-after-installing-models"></a>
### モデルのインストール後に容量が足りないとき

**原因：** ダウンロードした言語モデルはMacの容量を使います。必要な容量はインストールした言語やモデルによって異なります。

**対処方法：**
1. システム設定 → 一般 → 言語と地域 → 翻訳言語…に進んでください。
2. 使っていない言語の横の**削除**を押してください。
3. その言語のオンデバイス翻訳モデルが削除されます。
4. 必要になれば、いつでも再ダウンロードできます。

<a id="slow-translation-or-low-latency-vs-high-fidelity"></a>
### 翻訳が遅いときと翻訳方式の選び方

設定 → 翻訳で**優先する翻訳方式**を選べます：
- **速度優先（初期値）：** 速くて軽いため、日常的に文章を読むときに向いています。
- **品質優先：** macOS 26.4以降の対応デバイスでApple Intelligenceを使います。より自然な文章になる場合がありますが、すべての文章で表現が良くなるとは限りません。

> **翻訳方式の設定はmacOS 26.4以降でのみ有効です。** macOS 26.0–26.3ではApple翻訳の既定の方式を使うため、選択を変えても速度や精度は変わりません。

選んだ方式と言語の組み合わせでモデルを確認します。優先するモデルがなく、別の方式のモデルがインストールされていれば、リクエスト前にそのモデルを選びます。キャプチャの状態表示やライブ翻訳の情報アイコンから理由を確認できます。設定を変更したり、モデルを自動ダウンロードしたりはしません。

どちらの方式のモデルもない場合、エラーに言語の組み合わせを表示します。Apple Intelligenceのモデルがインストールされていても、速度優先のモデルまでインストールされているとは限りません。

翻訳が遅く感じる場合：
1. macOS 26.4以降なら、設定 → 翻訳で**速度優先**を試してください。
2. アプリを開きすぎてMacに負荷がかかっていないか確認してください。
3. 長い内容をキャプチャした場合、方式に関係なく翻訳に数秒かかることがあります。

<a id="feedback"></a>
## フィードバック

モデルのインストールに問題がある場合や、翻訳が引き続き失敗する場合：
1. GitHubの[SwiftyCrowのIssue](https://github.com/PangMo5/SwiftyCrow/issues)を確認してください。
2. macOSのバージョン、言語の組み合わせ、アプリに表示された正確なエラーメッセージをお知らせください。
3. 翻訳前にモデルのダウンロードが完了していたかもお知らせください。

<a id="reading-difficult-sources"></a>
## 読み取りにくい原文

コードや技術的な識別子として認識した部分は、訳文として描き直さず元のピクセルを保ちます。原文のコピーには引き続きOCR結果を使うため、識別子やコードの正確さが重要な場合は確認してください。

認識した文章に疑わしい単語が多い場合や、混在する文字の修復が不確かな場合は確認の目印が出ます。原文と比べるための案内であり、自動のスペル修正ではありません。小さい文字、ぼやけた文字、圧縮された文字、曖昧な用語は誤訳される場合があります。

印刷された台詞は画像の境界を使って隣の吹き出しと分けます。縦書きや回転した文字の読む方向を保ちます。模様のある背景では周囲の背景を参考に文字を消すため、原文に隠れた絵を正確に復元することはできません。
