# 変更履歴

SwiftyCrowの主な変更を記録しています。ウェブサイトとGitHubのリリースノートはこのファイルを基準に表示します。公開時にリリースワークフローがインストール・更新の案内を追加します。

<a id="2100-2026-09-17"></a>
## 2.10.0 (2026-09-17)

<a id="improvements"></a>
### 改善

- **原文の配置に沿った翻訳：** 段落の配置や文字のスタイルを原文に近く保ちます。コードやコマンドと認識した文字は翻訳せず、そのまま残します。縦書きも翻訳先の言語に合った方向で表示します。
- **読み取りにくい画面の認識を改善：** 印刷された吹き出しの境界、ルビ、回転した文字、複数言語が混在する文章の認識を改善しました。不確かな文字には確認の目印が表示されます。
- **キャプチャの拡大と移動：** ウインドウを移動し、ピンチ、スクロール、ドラッグで画像を詳しく確認できます。倍率をクリックすると全体が収まり、翻訳画像全体を元の解像度で保存・コピーできます。
- **ライブ翻訳：** 画面の変化に合わせて更新間隔を調整し、変化のない内容を省き、古い処理をキャンセルします。隠した翻訳を記憶した範囲とウインドウ位置で再開でき、ディスプレイを外した場合も見える画面に戻します。
- **インストール済みモデルを活用：** 優先するモデルがない場合は、別のインストール済みモデルを使って理由を表示します。ライブ翻訳の情報ボタンから詳細を確認できます。
- **わかりやすい翻訳メニュー：** キャプチャやライブ翻訳をすぐに開始でき、選んだ言語も確認できます。ライブ翻訳の操作項目はオーバーレイの表示中だけ現れます。
- **クイック設定と新機能の案内：** 初めて使う方は、最初のキャプチャまでに画面へのアクセス、言語のダウンロード、ショートカットを準備できます。既存の利用者には機能リリースの主な変更を案内し、どちらもメニューバーから開けます。
- **既定のショートカット：** ⇧⌘1でキャプチャ、⇧⌘2でライブ翻訳の範囲を選択できます。クイック設定や設定で変更でき、既存の独自設定は保持されます。
- **5言語に対応：** アプリ、ガイド、ウェブサイトを英語、韓国語、日本語、簡体字中国語、台湾向けの繁体字中国語で使えます。

<a id="fixes"></a>
### 修正

- **鮮明な範囲キャプチャ：** ドラッグで選択した範囲を画面のピクセルに合わせ、文字認識の前に余分な1行や1列へ画像が再サンプリングされるのを防ぎます。
- **選択した言語を正しく表示：** 設定ファイルの短い言語コードも、システム一覧の同じ言語と一致するようにしました。

<a id="configuration"></a>
### 設定

- 手動の`[capture].interval`設定は使わなくなり、ライブ翻訳が更新間隔を自動で調整します。

<a id="290-2026-07-30"></a>
## 2.9.0 (2026-07-30)

<a id="fixed"></a>
### 修正

- **ライブ翻訳とキャプチャが翻訳せず待ち続ける問題を修正：** アプリをしばらく使わなかった後、閉じてやり直すまで待機表示だけが続くことがありました。macOSはメモリが必要になると文字認識モデルを解放し、再読み込みには数十秒かかります。起動時、スリープ解除時、範囲の選択中にモデルを先読みするようにしたため、多くの場合は選択が終わる前に準備できます。待つ必要があるときは、単なる待機表示ではなく**文字認識を準備しています**と案内します。
- **ライブ翻訳を閉じると確実に停止：** 以前はウインドウを画面外へ移動するだけだったため、見えないアニメーションがCPUを使い続け、古い結果が次のキャプチャに混ざることがありました。現在は両方のウインドウを解放します。
- **待機表示が残る問題を修正：** 更新順が入れ替わると、別の操作で更新されるまで訳文なしで待機表示だけが残ることがありました。
- **別ウインドウで待ち続ける問題を修正：** ライブキャプチャごとにぼかし背景の生成がやり直され、広い範囲では処理がキャプチャ間隔より長くなると完了せず、ウインドウが空のままでした。

<a id="changed-1"></a>
### 変更

- **応答しない段階を案内：** 画面キャプチャ、文字認識、翻訳にそれぞれ制限時間を設け、どの段階が応答していないかを表示します。ライブ処理が1回失敗しても、翻訳全体を停止せず続行します。

## 2.8.0 (2026-07-15)

<a id="whats-new"></a>
### 新機能

- **必要なときに使うプリセット範囲：** 範囲を先に決め、必要なときに翻訳できます。前回の範囲を記憶するため、新しい**ライブ翻訳を表示／非表示**ショートカットやメニューの**前回の範囲に表示**／**ライブ翻訳を非表示**で、ドラッグし直さず切り替えられます。ゲームのパネルなど、ときどき確認する固定情報に便利です。オフにするとウインドウと処理をすべて終了し、再表示するまでキャプチャ・文字認識・翻訳を行いません。`[shortcuts] toggleLiveOverlay`または設定 → ショートカットで割り当ててください。 (#9)

<a id="changed-2"></a>
### 変更

- **設定画面を刷新：** システム設定のように左側に項目一覧、右側にグループ化した設定を表示する標準ウインドウになりました。サイズを変更でき、開いている間は通常のアプリウインドウとしてアクティブになります。
- **ライブ翻訳の表示を整理：** 移動ハンドルと同じく、**ライブ**と**×**ボタンもポインタが範囲内にあるときだけ表示します。進行表示は翻訳だけでなくキャプチャと文字認識も含むため、初回キャプチャが遅いときも処理中だと分かります。

## 2.7.0 (2026-06-18)

<a id="whats-new-1"></a>
### 新機能

- **原文位置での縦書き翻訳：** 日本語や繁体字中国語を含む縦書きのCJK文章を読む順序に沿って認識します。文字は上から下、列は右から左に配置し、原文の文字サイズを保って翻訳します。
- **文書構造を理解する認識：** 文章を読む順序の段落にまとめ、ルビを本文から分け、各ブロックの方向を検出します。漫画や段組みのページをよりきれいに認識できます。

<a id="fixed-1"></a>
### 修正

- **言語モデル未インストールの案内：** モデルがないときに次の操作を案内します。キャプチャした言語のモデルがなければ、結果ウインドウ、ライブ翻訳、別ウインドウ、メニューバーに案内が出ます。**設定を開く**でダウンロード先に移動し、**今後表示しない**で案内を非表示にできます。

<a id="changed-3"></a>
### 変更

- **文書解析に認識方式を統一：** テキスト・文書の切り替えを廃止し、常に文書の配置を解析します。`config.toml`の`[recognition]`テーブルは無視されます。

## 2.6.0 (2026-06-13)

<a id="breaking-changes"></a>
### ⚠️ 互換性に関わる変更

- **ライブ翻訳ショートカットの名前を変更：** `[shortcuts] toggleOverlay`が`liveOverlay`になりました。範囲の選択でライブ翻訳を開始・変更でき、Spaceでウインドウも選べます。以前の`toggleOverlay`は無視されるため、`liveOverlay`または設定 → ショートカットに割り当て直してください。
- **常設表示の設定を削除：** `[overlay] enabled`を削除しました。範囲やウインドウを選んでライブ翻訳を配置し、**×**で閉じます。以前のキーが残っていても無視されます。

<a id="whats-new-2"></a>
### 新機能

- **macOSと同じウインドウ選択：** 範囲の選択中に**Space**を押すとウインドウ選択に切り替わります。ポインタ下のウインドウが強調され、クリックで選択できます。通常のキャプチャは他のウインドウに隠れていても対象を撮影し、ライブ翻訳はその位置に配置されます。
- **ドラッグでライブ翻訳を開始：** 通常のキャプチャと同じように、**ライブ翻訳…**を実行して範囲をドラッグするかSpaceでウインドウを選ぶだけで翻訳が始まります。表示を有効にし、位置を合わせ、さらにライブをオンにする必要はありません。
- **組み込みの操作ボタン：** ライブ中は色付き、一時停止中は単色になる**ライブ**ハンドルと、閉じるための**×**ボタンを常に表示します。

<a id="changed-4"></a>
### 変更

- **常に入力を透過：** クリックやスクロールは背後のアプリに届きます。ライブハンドルで範囲を移動し、端でサイズを変えられます。ライブ範囲を配置している間だけウインドウが存在し、常設パネルや待機ガイドは残りません。
- **ショートカット記録欄を改善：** キーボード言語に関係なく`⌘S`のような英字のキー表記を保ち、1回のクリックで記録し、使用中の組み合わせを案内し、専用ボタンで消去できます。キャプチャの保存・コピーのキーは別の保存先ではなく`config.toml`の`[shortcuts]`テーブルに保存します。初期値は`⌘S`/`⌘C`/`⌘O`/`⌘T`です。グローバルショートカットは**Magnet**で登録します。

## 2.0.0 (2026-05-27)

<a id="highlights-1"></a>
### 主な変更

- **行ごとに原文位置で翻訳：** 認識した行の高さに合わせ、同じ位置に訳文を表示します。Apple翻訳のカメラモードに似た方式です。
- **浮かぶガラスの翻訳パネル：** 透明で枠のないパネルをドラッグ、サイズ変更でき、ポインタを重ねると自動で隠すこともできます。`⌘C`で現在の訳文をコピーします。
- **ライブモード：** 一定間隔で範囲を再キャプチャし、動作中は`LIVE`バッジが点滅します。
- **メニューバーアプリ：** Dockアイコンはありません。ウインドウを開かずに、1回のキャプチャ・ライブ切り替え・表示切り替えのグローバルショートカットを使えます。
- **原文の自動検出と動的な言語一覧：** Visionで原文の言語を検出し、インストールされたApple翻訳・文字認識の言語から一覧を作ります。言語をコードに固定しません。
- **行ごとの翻訳キャッシュ：** 同じ画面を再キャプチャすると、翻訳呼び出しを省きます。
- **1つのTOML設定：** 設定は`$XDG_CONFIG_HOME/SwiftyCrow/config.toml`に保存され、アプリ内の設定と相互に同期します。

<a id="under-the-hood"></a>
### 内部の変更

- **オンデバイス処理：** ScreenCaptureKit、Vision OCR、Apple翻訳を使い、すべての処理をデバイス上で行います。
- **新しいmacOS 26+ API：** **macOS 26以降**向けに、`SCScreenshotManager`、`RecognizeTextRequest`、直接利用する`TranslationSession` APIで構築しています。
- **自動アップデート：** Sparkleで自動更新を提供します。
